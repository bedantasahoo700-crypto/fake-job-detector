# 🚨 Fake Job Posting Detection System

An end-to-end Machine Learning project that detects whether a job posting is **real or fake** using a CatBoost classifier and provides a simple web interface using Streamlit.

---

## 📌 Project Overview

Online job fraud is increasing rapidly. This project aims to solve this problem by analyzing job descriptions and related details to predict whether a job posting is genuine or fraudulent.

The system uses structured job-related features and applies a CatBoost machine learning model for high-accuracy classification.

---

## 🎯 Objective

To build an AI-powered system that:
- Identifies fake job postings
- Helps users avoid online job scams
- Provides real-time predictions via a web interface

---

## 🧠 Machine Learning Approach

- Algorithm: CatBoost Classifier  
- Problem Type: Binary Classification  
- Output Classes:
  - 0 → Real Job
  - 1 → Fake Job  

CatBoost is used because it handles categorical features efficiently without extensive preprocessing.
